# 업데이트 효과 분석 v2: 보완 분석 결과 (2026-10-12)

기존 update_project 결과 중 약점 4곳을 다시 검증했다. 스크립트·결과는 모두 이 폴더(v2/)에 있고, 기존 파일은 건드리지 않았다.
실행: `update_project` 상위 폴더(archive)에서 `python update_project/v2/<스크립트>.py` (common.py가 캐릭터-일 캐시 `_cd.pkl`을 만든다).

## 1. 패치 2.4.0: 사전 추세는 '그룹 선택 방식'이 만든 착시였다
- 문제: 기존 이중차분은 패치 전 8주 동안 차이가 계속 줄어드는 추세가 있었다(접속일 기울기 -0.06/주, 95% CI가 0을 포함하지 않음).
  원인은 패치 직전 3주에 접속한 캐릭터만 골라서, 그 3주의 활동이 인위적으로 높아진 것이다.
- 보완(S3): 사전 8주 매주 접속한 캐릭터만 남기고(진입·이탈 효과 제거), 대조군을 40~69레벨로 넓힘 → 사전 추세가 0과 구별되지 않음.
- 결과 (처치군 사전 평균 대비, 괄호는 부트스트랩 95% CI)

| 주차 | 접속일 | 플레이 시간 |
|---|---|---|
| 0주 | +14% (+8~+20) | +29% (+20~+39) |
| 2주 | +11% (+5~+17) | +10% (+1~+21) |
| 3주 | +8% (+2~+15) | +1% (-9~+12) |
| 4주 | +4% (-2~+11) | -4% (-16~+7) |

  (1주차는 4/3~4/7 수집 공백으로 없음)
- 가짜 패치일 7개: 접속일 효과는 평균 +1%, 최대 +4%. 실제 0주·2주 값이 7개 모두보다 크다(가능한 최소 p=0.125).
- 플레이 시간은 가짜 날짜에서도 평균 -10%가 나와(70레벨 시간이 원래 서서히 줄어드는 경향) 접속일보다 덜 믿을 만하다.
- **결론 수정**: 기존 '추세 보정' 결과의 "10주 넘게 효과 지속"은 잘못된 사전 추세를 연장한 결과였다. 실제로는 플레이 시간은 약 2주, 접속 빈도는 약 3주 동안 올랐다가 원래대로 돌아왔다.

## 2. 패치 3.0.2 (대만 10/23): '반짝 효과' 결론은 수집 문제 때문에 과장됐다
- 패치일 확인: 10/23 점검이 15.5시간으로 평소(약 9시간)보다 길고, 신규 지역 The North Sea가 이날 처음 등장했다.
  (기존 메모의 '3.0.3 단절 시계열'은 실제로는 3.0.2 분석이다.)
- 보완 1: 실제·가짜 날짜 모두 같은 집단 기준을 적용(기준일 16일 전까지 생성된 캐릭터)하고, 모형 4종으로 비교했다.
- 보완 2: 수집 품질 점검 결과, 10/30~11/5 주에 블러드엘프 관측 비중이 35%에서 24%로 떨어졌다(다음 주에 37%로 복귀).
  접속 중 누락 비율도 1%에서 5.8%로 올랐다. 그래서 블러드엘프를 제외한 분석을 따로 했다.

| DAU 효과 (실제 vs 예측) | 1주차 | 2주차 |
|---|---|---|
| 전체, 선형·로그선형 49일 | +17% | +7% |
| 전체, 수준유지 14일 | +16% | +1% |
| 블러드엘프 제외, 49일 모형 | +24% | +17~18% |
| 블러드엘프 제외, 수준유지 14일 | +22% | +10% |
| 가짜 날짜 7개 (평균 ± 2sd) | 약 -2~-4% ± 7~9% | 약 -4~-8% ± 10~12% |

- 선형 28일 모형(+34%)은 10월 초의 급락을 추세로 연장해 과대추정하므로 제외했다.
- **결론 수정**:
  - 복귀 유입은 1주차에만 몰린다(1주차 +61~67%, 2주차 약 0%).
  - 그러나 DAU는 2주차에도 남아 있을 가능성이 높다(+1~+18%, 수집 누락을 보정할수록 커짐).
  - 따라서 "1주만에 효과 소멸"보다 "유입은 1회성, 돌아온 유저 일부는 2주차에도 남음"이 정확한 표현이다.
  - 플레이 시간은 2주차 수집 누락이 커서 판단을 보류한다.

## 3. 리치왕: 기준선을 '출시 직전 주' 대신 '공백기 이전 추세'로
- 주별 플레이 시간은 7~9월 약 4.4만 시간에서 10/2 주부터 약 2.6~3.3만 시간으로 33% 떨어졌다.
  - 이 공백기 동안 레벨·종족 구성, 접속 중 누락 비율, 라운드 간격은 정상이었다. 수집 문제가 아니라 실제 감소로 본다(원인은 데이터로 확인 불가).
  - 기존 분석의 +73%는 이 공백기를 기준으로 삼은 값이라, 대부분이 '회복분'이다.
- 7~9월 추세 대비 효과 (5~9월 추세 기준이면 괄호 안 값):

| | 출시 주 | 출시 후 6주 평균 |
|---|---|---|
| 접속 캐릭터 | +31% (+29%) | +18% (+15%) |
| 플레이 시간 | +12% (+16%) | +6% (+11%) |
| 데스나이트 제외 플레이 시간 | -17% (-13%) | -16% (-12%) |

- 늘어난 플레이 시간은 전부 데스나이트 몫이고, 기존 직업 캐릭터의 플레이 시간은 추세보다 낮았다.
  계정 ID가 없어 확인은 불가하지만, 기존 유저가 데스나이트로 갈아탄 '대체' 가능성을 시사한다.
- 사이클 전체: 공백기 손실 -10.2만 시간(7주) vs 출시 후 증가 +1.6만 시간(6주).
- 주의: 출시 전후로 수집 방식이 바뀌었다(라운드 간격 10.5분 → 12.4~15분, 접속 중 누락 1% → 4~5.5%). 그래서 출시 후 수치는 과소집계됐을 수 있고, 위 효과는 하한값으로 해석한다.

## 4. 복귀 유저: 길드 효과는 레벨 교란, 첫 주 재접속은 통제 후에도 남는다
- 리치왕 복귀자 780명, 로지스틱 회귀(4~6주 뒤 접속 여부):
  - 첫 주 길드 소속의 오즈비는 단독으로 2.0이다. 레벨·휴면 기간·휴면 전 길드를 넣으면 1.5(유의하지 않음), 첫 주 접속일을 넣으면 1.2, 플레이 시간까지 넣으면 1.0이 된다.
    → 길드 효과는 주로 '70레벨 복귀자가 길드도 있고 정착도 잘 한다'는 교란이었다.
  - 첫 주 2일 이상 접속의 오즈비는 레벨 등을 통제하면 4.8(3.4~6.7), 플레이 시간까지 통제해도 2.9(1.9~4.4)다.
  - 휴면 기간이 길수록 정착률이 낮다(log 휴면일 오즈비 0.79~0.83).
- 연중 복귀 이벤트 2.3만 건(A/B 설계의 근거):
  - 2일차 재접속의 오즈비는 2.20에서 통제 후 1.85로 줄었다. 평균 한계효과는 +19%p에서 +14%p다. 차이의 약 1/4은 교란이고, 나머지는 여전히 크다.
  - 70레벨만(OR 2.03), 60레벨 미만만(OR 1.77) 따로 봐도 같은 방향이다.
- A/B 설계에 주는 함의:
  - 2일차 재접속을 +5%p 올려도, 그 관계가 전부 인과라고 가정할 때 4~6주 잔존은 약 +0.7%p 오른다.
  - 이를 1차 지표로 검정하려면 그룹당 약 7.5만 명이 필요하다.
  - 따라서 1차 지표는 2일차 재접속으로 두고, 장기 잔존은 가드레일 및 누적 관측 지표로 두는 기존 설계가 맞다.
